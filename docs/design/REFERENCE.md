# Laboratory visual reference

The full-screen `lab-concept.png` was generated with the built-in Image Gen tool as a design reference on 2026-09-06. It is not simulation evidence or an application background. All scientific graphics in the running product are code-native views of kernel state.

Design brief: calm scientific instrument; paper `#f5f4ef` rails around a forest `#111c19` living canvas; ink `#20352c`; amber food and sage home signals; serif ANT/headline, sans-serif controls and monospaced measurements. Full desktop instrument: experiment/rules/parameter rail, living world with four layers, transport, colony/individual rail, and interpretation strip. Required interactions: pause, step, seeded restart, editable parameters, actual metrics and local ant inspection. Avoid games, fake metrics, invented trails and decorative dashboard panels. Mobile preserves the world first.

The source prompt also specified the user's copy “The first trail”, “One nest. One food source. No leader”, the three local rules and “No ant planned this route.” Static illustrative numbers were allowed only inside this concept. The implementation substitutes computed state from tick zero.

Component system: flat rails with fine separators; 4px controls; sage selected states; 44px main interaction targets; semantic headings; a single drawing surface; progressive disclosures for run files, metrics and methodology. Fonts are self-hosted DM Sans and IBM Plex Mono; the serif stack is Georgia/Times.

Intentional adaptations for the scientific product: precise circular obstacle boundaries instead of raster rocks; actual heatmaps instead of illustrative dust; state-dependent interpretation; explicit observational-home notice; numeric seed editing/new-seed, 100× and run-file tools; accessible ant selector; shorter responsive canvas and natural vertical scrolling to retain these controls. No mockup raster or raster ant emblem is inserted in the app. Latest rendered evidence and comparison are in `../VALIDATION.md`.
